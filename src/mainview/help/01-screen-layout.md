# 画面構成

VJAを起動すると、次の5つのエリア（下の画像）が表示されます。

![VJAの画面](help/screenshot.jpg)

| エリア | 説明 |
|--------|------|
| メニュー・ツールバー | 上段のメニュー（ファイル・編集・表示・プロジェクト・設定・ヘルプ）と、下段のよく使うボタン（新規・開く・保存・元に戻す・実行・コンパイルなど） |
| ツールボックス・画面一覧 | 配置できるウィジェットの一覧（左側）と、その下の画面（フォーム）の一覧 |
| フォームキャンバス | ウィジェットを配置・編集するエリア（中央） |
| プロパティパネル | 選択中のウィジェットの設定を編集するエリア（右側） |
| ステータスバー | 現在の状態（選択中のツール・座標・ウィジェット数・グリッドとスナップのON/OFF） |

## 基本の流れ

1. 左のツールボックスから、キャンバスへウィジェットを配置する
2. 右のプロパティパネルで、名前や見た目を設定する
3. プロパティパネルの「イベント」から、クリック時などの処理を書く（→「イベントエディタ」）
4. ツールバーの「実行」で動かして確かめる
