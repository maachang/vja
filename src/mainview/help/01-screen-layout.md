# 画面構成

VJAを起動すると、次の5つのエリアが表示されます。

```
┌─────────────────────────────────────────────────────────┐
│  ツールバー（実行・コンパイル・定数・AI設定・その他）        │
├──────────┬──────────────────────────────┬───────────────┤
│ ウィジェット │      フォームキャンバス        │  プロパティ   │
│  パネル   │   （ここにウィジェットを配置）    │   パネル     │
├──────────┴──────────────────────────────┴───────────────┤
│  ステータスバー（フォーム名・ウィジェット数・座標情報）       │
└─────────────────────────────────────────────────────────┘
```

| エリア | 説明 |
|--------|------|
| ツールバー | 実行・保存・各種設定ダイアログを開くボタン |
| ウィジェットパネル | 配置できるウィジェットの一覧（左側） |
| フォームキャンバス | ウィジェットを配置・編集するエリア（中央） |
| プロパティパネル | 選択中のウィジェットの設定を編集するエリア（右側） |
| ステータスバー | 現在の状態（フォーム名・座標など） |

## 基本の流れ

1. 左のウィジェットパネルから、キャンバスへウィジェットを配置する
2. 右のプロパティパネルで、名前や見た目を設定する
3. プロパティパネルの「イベント」から、クリック時などの処理を書く（→「イベントエディタ」）
4. ツールバーの「実行」で動かして確かめる
