# JSコード生成

イベントのYAMLから、AIがJavaScriptコードを作ります。

## 前提

「AI接続設定」で、エンドポイント（ローカルLLMやOpenAIのURL）を設定しておきます。

## 手順

1. イベントエディタを開く
2. **YAMLタブ**に、処理の指示を書く
   - 日本語の文章でやりたいことを書き、**「✨ YAMLドラフト生成」**でYAMLの下書きを作ることもできます
3. **「🤖 JSコード生成」**ボタンを押す
4. 確認ダイアログで「OK」を押すと、現在の内容が保存され、生成が始まる
5. 生成が終わると、**JavaScriptタブ**に結果が表示される

## YAMLの書き方のコツ

- 処理の目的を具体的に書く（例:「検証してからINSERTする」）
- 使うウィジェット名を明示する
- 遷移先のフォーム名を書く
- テーブルを使う処理では、右パネルの「🗄 テーブル一覧」で該当テーブルをONにする

## うまくいかないとき

- **🎲 再生成**: 同じ間違いを繰り返すときに、ランダム性を少し上げて作り直します。
- 生成後は、自動で文法やAPIの使い方がチェックされ、必要なら1回自動で作り直します。
- **📌 記録 / 🕐 履歴**: うまくいったYAMLとJSを記録しておき、あとで戻せます。作り直す前に記録しておくと安心です。
