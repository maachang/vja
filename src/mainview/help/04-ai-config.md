# AI接続設定

## 開き方

メニュー［設定］→ **「AI接続設定…」** を選びます。

## 設定項目

| 項目 | 説明 |
|------|------|
| AI生成を有効 | AI機能のON/OFF |
| エンドポイント | llama.cppやOpenAI互換APIのURL |
| API Key | OpenAIなどのキー（ローカルLLMでは不要） |
| ルーターモード | 複数モデルを切り替えるサーバー向け（下記） |
| Max Tokens | 生成するトークン数の上限（空ならサーバー依存） |
| temperature | 生成のランダム性（0.0〜1.0、空ならサーバー依存） |
| 推論モード | thinkingモードのON/OFF（対応サーバーのみ） |
| モック実行検証 | 生成コードをダミー値で試し実行し、実行時の例外を検出する（初期値ON） |

### ルーターモード

- **OFF**: モデル名を指定しない。llama.cppのように、起動時にモデルが決まっているサーバー向け。
- **ON**: モデル名を指定する。ollamaやOpenAIのように、複数モデルを切り替えるサーバー向け。「🔄 更新」でモデル一覧を取得できます。

## 設定例

**llama.cpp（ローカルLLM）**: 起動時にモデルが決まるので、ルーターモードは不要です。

```
エンドポイント: http://localhost:8080
API Key:        （空のまま）
ルーターモード:  OFF
```

**ollama（ローカルLLM）**: 複数モデルを切り替えられるので、ルーターモードをONにしてモデル名を指定します。

```
エンドポイント: http://localhost:11434
API Key:        （空のまま）
ルーターモード:  ON
モデル名:        llama3.2 など
```

**OpenAI**: 軽量で低コストなモデル（`gpt-4o-mini` など）を使えます。

```
エンドポイント: https://api.openai.com
API Key:        取得したOpenAIのAPIキー
ルーターモード:  ON
モデル名:        gpt-4o-mini など
```

**その他のOpenAI互換API**: `/v1/chat/completions` に対応したサービスなら使えます。エンドポイントとAPI Keyをサービスに合わせ、ルーターモードもサービスの仕様に合わせます。

ルーターモードをONにすると、「🔄 更新」でサーバーからモデル一覧を取得できます。

## 使い分けの目安

- **ローカルLLM**（完全無料・PC内で完結）: Windows AI PC（Copilot+ PC）や、Apple SiliconのMacで、手順に沿ってセットアップできます。ルーターモードONで `http://localhost:8080` を使います。
- **OpenAIなどのクラウドAPI**: ローカルLLMの環境がないPC向け。1イベント単位の細かい依頼なので、費用はごくわずかです。
