# プロジェクトとフォーム

## 新規作成・保存・読み込み

| 操作 | 方法 |
|------|------|
| 新規作成 | ツールバー左端の「新規」。未保存の変更があると確認ダイアログが出ます |
| 保存 | 「保存」ボタンまたは `Ctrl+S`。初回は保存ダイアログ、2回目以降は同じファイルへ上書き |
| 読み込み | 「開く」で `.vjaproj` ファイルを選ぶ |

保存形式は `.vjaproj`（JSON形式）です。

## ウィザードで雛形を作る

メニュー［ファイル］→［ウィザードでプロジェクト作成…］で、作りたいものを日本語で答えるだけで、フォームとDBテーブルの雛形を一括で作れます（AI接続設定が必要です → 「AI設定」）。

1. AIの質問に答える（「完了」でいつでも終了できます）
2. 提案されたフォーム一覧とテーブル候補を確認する
3. 「生成開始」で、フォームの画面レイアウトが順に自動生成される

ウィザードは雛形づくりまでです。次の点は生成後に自分で行います。

- フォーム間の画面遷移（ボタンのイベントで `vja.form.navigate()` を書く）
- テーブルのカラム構成（ウィザードは名前と説明だけ登録します）
- 生成に失敗したフォームのやり直し（空のまま残ります）

## フォームの管理

1つのプロジェクトに複数のフォーム（画面）を持てます。

- **追加**: ツールバー右の「画面:」にある「＋」
- **切り替え**: 「画面:」のプルダウンでフォームを選ぶ
- **起動フォーム**: 「画面:」の右端の★を押すと、アプリ起動時の最初の画面になります

ウィジェットを選ばずにプロパティパネルを見ると、フォーム自体の設定（フォーム名・幅/高さ・背景色・フォームテーマ・フォーム定数）を編集できます。フォーム名は `vja.form.navigate()` で画面を指定するときに使います。
