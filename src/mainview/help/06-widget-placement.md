# ウィジェットの配置と編集

## 配置・移動・リサイズ

1. 左のツールボックスで、置きたいウィジェットをクリック
2. フォームキャンバス上でクリックすると配置される
3. ドラッグで移動、選択時に表示されるハンドルのドラッグでリサイズ

## ショートカット

| 操作 | キー |
|------|------|
| コピー | `Ctrl+C` |
| 貼り付け | `Ctrl+V` |
| 削除 | `Delete` / `Backspace` |
| 元に戻す | `Ctrl+Z` |
| やり直し | `Ctrl+Shift+Z` |
| 複数選択 | `Ctrl` を押しながらクリック |

## AIで画面デザインを自動生成する

手で1つずつ置く代わりに、YAMLで要件を書いてAIにレイアウトを作らせられます（AI接続設定が必要です → 「AI設定」）。

1. ウィジェットを選ばずにフォームを選択する
2. プロパティパネルの「🤖 AIでフォーム設計…」を押す
3. YAMLに次の項目を書く

| 項目 | 内容 |
|------|------|
| 説明 | 画面の目的 |
| フォームレイアウト | 「2カラム構成」「ボタンは右下」などの方針（最優先で解釈されます） |
| 参照テーブル | 入力項目の元にするテーブル名 |
| 入力項目 | 置きたい入力欄の一覧 |
| アクション項目 | 置きたいボタンの一覧（書いた数だけ生成されます） |

4. 必要なら「追加指示」を書き、「🤖 生成」を押す

### 注意

- **このフォームに配置済みのウィジェットは全て削除され、生成結果に置き換わります。** 設定済みのイベントコードも失われます
- 実行前に確認ダイアログが出ます。間違えても `Ctrl+Z` で戻せます
- `selectBox` / `listBox` の選択肢は生成されないため、配置後に自分で設定します
