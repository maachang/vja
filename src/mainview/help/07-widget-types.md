# ウィジェットの種類とプロパティ

## ウィジェット一覧

| アイコン | 種類 | 説明 |
|---------|------|------|
| ⬜ | button | クリックできるボタン |
| 🏷️ | label | 文字の表示（読み取り専用） |
| 📝 | text | 1行の入力欄（入力タイプを指定可） |
| 📄 | textarea | 複数行の入力欄 |
| ☑️ | checkbox | チェックボックス |
| 🔘 | radioButton | ラジオボタン |
| 🔽 | selectBox | ドロップダウン選択 |
| 📋 | listBox | リスト選択 |
| 🗃️ | テーブル | 表形式のデータグリッド |
| 📊 | progress | プログレスバー |
| 🗂️ | groupBox | ウィジェットをまとめる枠 |
| 🖼️ | image | 画像表示 |
| 🔲 | QRコード | 指定した文字列のQRコードを表示 |
| 📝 | マークダウン | Markdownを整形して表示 |
| 📅 | 日付/時刻 | 日付・時刻・日時の入力 |
| 🎚️ | スライダー | スライダー入力 |
| ↔️ / ↕️ | 水平scroll / 垂直scroll | スクロールバー |

## 共通プロパティ

| プロパティ | 説明 |
|-----------|------|
| 名前 | ウィジェットを識別するID。コードから `vja.widget.getValue('名前')` のように参照します |
| X / Y | 配置座標 |
| 幅 / 高さ | サイズ |
| 表示 | 表示/非表示の初期状態 |
| 説明 | ウィジェットの説明。AIがコードを作るときのヒントになります |

ウィジェットごとの固有項目（文字、色、枠線、選択肢など）は種類により異なります。

## フォームテーマとの連動

新しく置いたウィジェットには、フォームのテーマ（フォント・文字サイズ・文字色・ベースカラー）が自動で適用されます。連動する項目は種類によって違います（例: ラベルはフォントのみ、ボタンはフォントと色）。

- フォーム側のテーマを変えると、連動中のウィジェットへ反映されます
- ウィジェット個別のフォントや色を直接変えると、そのウィジェットは連動の対象から外れます
- 連動に戻すには、プロパティパネルの「↺ テーマに戻す」を押します

## textウィジェットの入力タイプ

| タイプ | 説明 |
|--------|------|
| text | 通常の入力 |
| password | パスワード（伏せ字） |
| number | 数値 |
| email | メールアドレス |
| tel | 電話番号 |
| url | URL |
