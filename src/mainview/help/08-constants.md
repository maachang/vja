# 定数

定数は、URLや税率のような「アプリで使う固定値」を、コードの外で管理する機能です。

## 開き方

ツールバーの「定数」（またはメニューの「定数の編集…」）を押します。上部のタブで、2種類の定数を切り替えて編集できます。

| タブ | 使える範囲 |
|------|-----------|
| 🌐 全体（全フォーム共通） | 全てのフォーム |
| 📄 このフォーム: フォーム名 | 現在のフォームだけ |

- 「保存」を押すと、両方のタブの内容をまとめて保存します。タブを切り替えても、編集中の内容は消えません。
- 同じ名前の定数があるときは、**フォーム定数が優先**されます。フォームのタブでは、全体の定数と同じ名前の行に「⚠ 全体の同名の定数を、このフォームでは上書きします」と注意が出ます。
- 同じタブの中に同じ名前があると、保存できません。

## コードから使う

```javascript
const apiUrl = vja.const.get('API_URL', 'http://localhost:3000');
const all = vja.const.getAll();
```

- `vja.const.get(名前, 既定値)` は、フォーム定数→グローバル定数の順で探し、どちらにも無ければ既定値を返します。
- `vja.const.getAll()` は、使える定数をまとめて返します。
