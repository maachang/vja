# バリデーション（入力チェック）

入力チェックのルールを、コードを書かずに画面上で定義できます。チェック処理そのものをAIに書かせる必要がないので、ローカルLLMでも安定して生成できます。

## 定義する

1. メニュー［プロジェクト］→「バリデーション定義…」を開く
2. 「＋ バリデーション追加」を押し、定義名を付ける（例: `ログイン入力チェック`）
3. ルールを追加する

| 項目 | 説明 |
|------|------|
| ウィジェット名 | チェック対象のウィジェット |
| 条件 | チェックの種類（下表） |
| NOT | 判定を反転する（「〜でない」） |
| arg1 / arg2 | 条件ごとの引数（上限や範囲など） |
| メッセージ | 不合格のときに表示するメッセージ |

## 条件の種類

| 条件 | 内容 | arg1 | arg2 |
|------|------|------|------|
| 必須 | 空でないこと | — | — |
| 最大文字数 | 文字数の上限 | 上限 | — |
| 最小文字数 | 文字数の下限 | 下限 | — |
| 数値範囲 | 数値の範囲 | 最小値 | 最大値 |
| 数値のみ / 整数のみ | 数値・整数の形式 | — | — |
| メール形式 / URL形式 | メール・URLの形式 | — | — |
| 電話番号 / 郵便番号 | 電話番号・郵便番号の形式 | — | — |
| 日付形式 | `YYYY-MM-DD` の形式 | — | — |
| 英数字のみ / 英字のみ | 英数字・英字だけ | — | — |
| ひらがなのみ / カタカナのみ | ひらがな・カタカナだけ | — | — |
| 正規表現 | 正規表現に合うこと | 正規表現 | — |

## イベントで使う

イベントエディタの右パネルにある「✅ 検証」のプルダウンで、定義名を1つ選びます（「（なし）」も選べます）。YAMLには何も書きません。

選ぶと、生成されるJavaScriptの先頭に次の1行が自動で入ります。

```javascript
if (!await vja.validate.run('ログイン入力チェック')) return;
```

不合格のルールがあると、そのメッセージが表示され、以降の処理は実行されません。

コードを手で書くときも、同じ1行を書けば使えます。
