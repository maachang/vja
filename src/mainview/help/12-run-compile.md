# 実行とコンパイル

## プロジェクト情報

ツールバーの「情報」で、プロジェクトの基本情報を設定します。

| 項目 | 説明 |
|------|------|
| プロジェクト名 | アプリ名。コンパイル時の出力フォルダ名などに使われます |
| バージョン | バージョン番号（例: 1.0.0） |
| 説明 | プロジェクトの説明 |
| 作成者 | 作成者名 |
| 会社・組織名 | 所属組織名 |

**コンパイルにはプロジェクト名の設定が必須です。**

## テスト実行

ツールバーの「実行」で、いまのプロジェクトを実行ウィンドウで動かせます。実行中は「停止」ボタンで止められます。

実行中にエラーが起きたときは、ツールバーにエラー一覧のボタンが現れます。

## コンパイル

テスト実行で問題がなければ、ツールバーの「コンパイル」で配布用のアプリを作れます。

1. 「情報」でプロジェクト名を設定する
2. 「コンパイル」を押し、確認ダイアログで「OK」を押す（ビルドには時間がかかります）
3. 完了後、出力先フォルダを開くか聞かれる

### 出力先

```
~/.vja-apps/VJAFormDesigner/dist/{プロジェクト名}/artifacts/
```

この `artifacts` フォルダに、使っているOSに合わせた配布用ファイルが作られます。
