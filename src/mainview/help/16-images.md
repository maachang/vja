# 画像管理

画像管理は、画面の飾りやロゴのような「小さな画像」をプロジェクトに登録して、名前で使う機能です。

## 開き方

メニュー［プロジェクト］→「画像管理…」を選びます。2段目のツールバーの「画像」ボタンからも開けます。

- 「＋ 画像を追加」で、画像ファイルを登録します（複数選択できます）。
- 名前は、ファイル名から自動で付きます。表の「名前」欄で変更できます。
- 登録できるのは png / jpg / gif / webp で、**1枚あたり300KBまで**です。
- 画像はプロジェクトファイルに保存されます。コンパイルしたアプリにも含まれます。
- 大きな画像を扱う場合は、外部のURL（https）を使ってください（下の「コードから画像を差し替える」を参照）。

## image ウィジェットに画像を表示する

image ウィジェットを選ぶと、プロパティパネルの「Image」に「🖼️ 選択…」ボタンが出ます。押すと、登録した画像がサムネイルで並ぶので、クリックして選びます。画像が多いときは、上の欄に画像名の一部を入れて絞り込めます。「（なし）」を選ぶと画像を外せます。画像の登録は、ポップアップ下部の「画像管理…」から開けます。

## コードから画像を差し替える

```javascript
// 画像管理に登録した画像を、名前で表示する
vja.widget.set('imgLogo', 'ロゴ');

// 外部のURLを表示する
vja.widget.set('imgPhoto', 'https://example.com/a.png');
```

- `vja.widget.set` に渡す値は、次のように判定します。
  - `http://` または `https://` で始まる: 外部のURLとして表示します。
  - `data:image/` で始まる: 画像のデータとして表示します。
  - それ以外: 画像管理に登録した画像の名前として表示します。名前が無ければ、画像は空になります。
- 登録した画像のデータそのものが必要な場合は、`vja.image.get('名前')` で取得できます（名前が無ければ `null`、`await` は付けません）。
- 外部のURLは、画像を配っているサーバーによっては、表示できないことがあります（例: 参照元の確認で拒否される場合）。その場合は、画像管理に登録してください。

## 名前の変更と削除

- 名前を変えると、image ウィジェットの設定は自動で更新されます。コードに書いた `vja.image.get('旧名')` は更新されないので、手で直してください。
- 画像ウィジェットで使っている画像を削除すると、そのウィジェットの画像は空になります（確認が出ます）。

## 以前のプロジェクトを開いたとき

以前のバージョンで image ウィジェットに直接入れた画像は、開いたときに自動で画像管理へ移ります（名前は image1, image2…）。
