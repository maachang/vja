# 設定・パラメータ管理系

## 概要
システム全体で共有される設定値や区分値（コードマスタ）のような、件数が少なく単純な構造のデータを管理する骨格。マスタ管理系の簡易版に位置づけられる。

## テーブル構成の型

```
例: 区分マスタ
- settings
  - id            INTEGER PRIMARY KEY
  - key           TEXT NOT NULL   -- 設定キー（例: "taxRate"）
  - label         TEXT NOT NULL   -- 表示名（例: "消費税率"）
  - value         TEXT NOT NULL   -- 値（文字列で保持し、用途に応じて変換）
  - note          TEXT
```

## 画面構成の骨格（重要）
- **一覧画面（1つ）のみで完結させる**。datagrid上で直接値を編集できる形（インライン編集）にするか、行クリックで小さな編集フォーム（同一画面内）を出す程度にとどめる
- 検索条件・詳細画面・登録専用画面のような、マスタ管理系で許容される構成すら不要なことが多い。件数が少ないことを前提に、極力シンプルな1画面構成にする

## AIが陥りやすい失敗（回避したい点）
- 件数が少ないにも関わらず、マスタ管理系と同じ規模感（検索条件・登録画面・削除確認等）をフルセットで作ってしまう（過剰設計）
- 設定値の型（数値・真偽値・文字列等）を意識せず、常にテキスト入力のみにしてしまう
